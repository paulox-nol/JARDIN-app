# JARDIN

Application Mac pour concevoir, documenter et entretenir un jardin, hors connexion.

Ce dépôt ne contient que les versions publiées de l’application.

## Installer

1. Télécharger le fichier `JARDIN-….dmg` de la [dernière version](https://github.com/paulox-nol/JARDIN-app/releases/latest).
2. Ouvrir le `.dmg` et glisser **JARDIN** sur le dossier **Applications**.
3. Premier lancement : macOS bloque l’application, qui n’est pas notarisée par Apple. Ouvrir **Réglages Système → Confidentialité et sécurité**, puis cliquer **Ouvrir quand même** en face de JARDIN. Cette étape n’est demandée qu’une fois.

Configuration requise : Mac Apple Silicon (M1 ou plus récent), macOS 13 ou plus récent.

## Mises à jour

Au lancement, JARDIN vérifie s’il existe une nouvelle version et propose de l’installer. Elle s’applique au lancement suivant.
